# Streaming Analytics — Analyse des habitudes de visionnage

## Présentation du projet

Ce projet porte sur l'analyse et la visualisation des habitudes de visionnage de séries sur différentes plateformes de streaming. Il utilise Python pour explorer les données, calculer des indicateurs et produire des visualisations facilitant la compréhension des comportements de visionnage.

## Objectifs

* Explorer les habitudes de visionnage.
* Analyser les durées et les horaires de visionnage.
* Étudier la répartition des contenus par plateforme et par genre.
* Identifier des tendances à partir des données disponibles.
* Présenter les résultats sous forme de graphiques.

## Technologies utilisées

* Python
* Pandas / NumPy
* Matplotlib / Seaborn
* CSV pour les données et résultats

## Structure du projet

* `code.py` : script principal d'analyse
* `visionnage_series.csv` : données de visionnage
* `resultats_analyse.csv` : résultats de l'analyse
* Fichiers `.png` : visualisations générées

## Visualisations

Les graphiques disponibles illustrent notamment :

* La durée moyenne de visionnage
* La durée totale par plateforme
* La fréquence des heures de visionnage
* La répartition des genres par plateforme
* Les habitudes selon les jours et les périodes

## Exécution

1. Installer Python.
2. Installer les bibliothèques réellement utilisées par le projet.
3. Télécharger ou cloner le dépôt.
4. Vérifier la présence des fichiers CSV attendus.
5. Exécuter `code.py`.

## Principaux résultats

- Analyse de la durée moyenne de visionnage.
- Comparaison du temps de visionnage entre les plateformes.
- Identification des horaires de visionnage les plus fréquents.
- Analyse de la répartition des genres.
- Analyse des habitudes selon les jours et les périodes.
